## Project overview

ALFXION-TECH HUB is an ICT solutions organisation that provides technology products and support services to individuals, small businesses, and corporate clients. The database design supports customer management, products, orders, payments, deliveries, inventory, and IT support requests.

The repository gives a practical implementation foundation for the portfolio, including SQL schema definitions, sample queries, indexing examples, MongoDB document structures, and cloud deployment concepts.
